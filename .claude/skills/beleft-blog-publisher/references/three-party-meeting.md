# 3자회의 — GPT 집필 · 제미나이 검증 · 클로드 최종검토

2026-10-02 마리님 지시: "항상 3자회의를 통해서 작성해줘. 글솜씨는 GPT가 더 좋으니까 GPT한테 맡기고, 쓰다가 검토/검수가 필요한 부분이 있으면 제미나이가 정보탐색해주고. 클로드는 꼭 항상 브랜드 핏에 맞는지 없던 얘기가 생긴 건 아닌지 최종검토해줘."

## 왜 이렇게 나누나

- 글을 쓴 쪽이 자기 글을 채점하면 후하다(brand-voice-editor 판정 분리 원리). 집필(GPT)과 판정(클로드)을 나눈다.
- GPT는 문장이 매끄러운 대신 그럴듯한 사실을 지어낼 수 있다. 그래서 **브리프에 준 사실만 쓰게** 하고, 외부 지식은 제미나이가 검색 근거로 확인한다.
- 클로드는 노션·스킬의 브랜드 기록에 접근할 수 있어서 "없던 얘기"를 가장 잘 잡는다.

## 호출 경로 (위에서부터 시도)

| 순서 | GPT | 제미나이 |
|---|---|---|
| 1 | OpenAI API — `scripts/ask_gpt.py` (`OPENAI_API_KEY`) | Gemini API + Google 검색 그라운딩 — `scripts/ask_gemini.py` (`GEMINI_API_KEY`) |
| 2 | ChatGPT 웹은 **자동 조작 금지**(OpenAI 약관이 프로그램 방식 출력 추출을 금지). 마리님이 직접 붙여넣어 받은 원고만 쓴다 | Gemini 웹(gemini.google.com, 마리님 Pro 계정) — 브라우저 도구 필요 |
| 3 | 불가 → SKILL.md 2절 "쓸 수 없을 때" | 불가 → 외부 사실 주장은 전부 빼거나 `[확인 필요]` |

- 키는 클라우드 세션이면 환경(Environment) 설정의 환경변수/시크릿으로 넣는다. 키 값은 출력·기록 금지.
- 모델은 환경변수 `GPT_MODEL`, `GEMINI_MODEL`로 바꿀 수 있다. 스크립트 기본값(gpt-5, gemini-2.5-pro)은 안전한 하한일 뿐이다. 2026-10 조사에서 더 새 모델(GPT-6 계열, Gemini 3.x)이 2차 출처로 보고됐으나 공식 페이지를 열지 못해 미확정 — 첫 실행 전에 공식 모델 목록에서 확인하고 설정한다. 사용한 모델명은 발행 메모에 남긴다.
- 웹 UI 경로에서는 개인화(메모리)가 섞일 수 있다. 새 대화(임시 채팅)에서 브리프 전체를 붙여 넣는다.

## 1단계: 클로드 → 브리프 작성

`brief-N.md`로 저장. 형식:

```
# 글감 N: <글감>
핵심 질문: <큐의 핵심 질문>
티어: <티어> / 유도 상품: <유도 상품>
## 써도 되는 사실 (이것 외의 브랜드 사실은 만들지 말 것)
- <fact-guard A에서 이 글에 필요한 것만, 출처와 함께>
## 쓰면 안 되는 것
- <fact-guard B 전체 + 이 글에서 특히 위험한 것>
## 채널별 요구
<아래 채널 포맷 복사>
## 이미지 자리
- 🎨 IMG: <영문 프롬프트> — 채널별 2~3개. 제품 실물 자리는 "PHOTO: 실사진" 으로 표시
```

## 2단계: GPT 집필 프롬프트

```
너는 한국 유아동 패션 브랜드 '비리프엔젤(BE:LEFT ANGEL)'의 블로그 작가다.
아래 브리프만 근거로 4개 채널 원고를 쓴다.
규칙:
1) 브리프 "써도 되는 사실"에 없는 브랜드 관련 사실(수치·기간·인증·경력·공장·유일성)은 절대 만들지 말고 [확인 필요]로 남겨라.
2) 브랜드 밖의 일반 지식(식물 염료, 세탁, 보존 연한 등)을 쓸 때는 문장 끝에 [검증요청]을 붙여라.
3) 금지어: 싸다, 저렴, 가성비, 할인, 세일, 특가, 최저가, 무조건, 100% 안전, 특허, 세계 최초, 유일, 완치, 치료.
4) 톤: 따뜻하고 차분하게. 겁주지 않는다. 과학 사실은 쉬운 말로. 엄마가 실수해도 괜찮다는 태도.
5) 출력은 채널마다 "=== 채널명 ===" 머리줄, 다음 줄 "제목: ...", 그 아래 본문(마크다운).
<브리프 전문>
```

## 3단계: 제미나이 검증 프롬프트

GPT 원고에서 `[검증요청]` 문장과, 클로드가 보기에 확인이 필요한 주장을 뽑아 보낸다.

```
다음 주장들을 Google 검색으로 확인해 줘. 각 주장마다:
- 판정: 사실 / 부분적으로 사실 / 근거 없음 / 틀림
- 근거 URL 1~3개 (공공기관·학술·제조사 공식 우선, 블로그·쇼핑몰 제외)
- 고쳐 쓴다면 안전한 표현 한 줄
글을 새로 쓰지 말고 판정만 돌려줘.
<주장 목록>
```

판정 반영 규칙: "근거 없음/틀림"은 삭제하거나 클로드가 안전한 표현으로 바꾼다. "부분적으로 사실"은 제미나이 제안 표현으로 바꾼다. 근거 URL은 노션 초안 맨 아래 "참고" 토글에 남긴다(발행 본문엔 채널 성격에 맞게 선택).

## 4단계: 클로드 최종검토

SKILL.md 3절. 불합격이면 GPT에 아래 형식으로 돌려보낸다(최대 2회):

```
다음 문장들을 고쳐 다시 써 줘. 다른 문장은 건드리지 마.
- "<걸린 문장>" → 이유: <…> → 방향: <…>
```

## 채널 포맷

| 채널 | 언어·화자 | 분량 | 구조 |
|---|---|---|---|
| 티스토리 | 한국어, 정보형 존댓말("~입니다/~예요" 혼용) | 2,000~3,000자 | H2 소제목 4~6개, 첫 문단에 핵심 답(AEO), 끝에 요약 3줄 + 자연스러운 자사몰 연결 1회 |
| 네이버 | 한국어, 1인칭 대화형("~해보려고요", 마리님 화자) | 1,500~2,500자 | 짧은 문단, 사진 사이사이, 공감 도입 → 경험 → 정보 → 마무리. 티스토리와 문장이 겹치지 않게(유사문서 판정 방지) |
| 워드프레스 | 한국어, 자료형 | 1,500~2,500자 | 정의 → 표(비교·수치) → 체크리스트 → FAQ 3개. 감성 문장 최소 |
| 블로그스팟 | 영어(원어민 문장, 번역투 X), 해외 부모 대상 | 900~1,400 words | Q 형식 제목, 한국 문화 맥락 1문단 설명, H2 4~6개, 끝에 brand note 1문단 |

모든 채널: 금지어 없음, 같은 이미지 마커 체계(`🎨 IMG: img<N>-<k> <영문 프롬프트>`).
